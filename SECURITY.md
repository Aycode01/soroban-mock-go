# Security Policy

`soroban-mock-go` is a local development and testing tool. It is not intended for production environments, and the code is not audited for cryptographic security. **Do not use this tool with production secrets or real mainnet keys.**

## Reporting a Vulnerability

If you discover a security issue that affects the safe usage of this tool in a local environment (e.g. arbitrary code execution through the configuration file or RPC server), please let us know.
